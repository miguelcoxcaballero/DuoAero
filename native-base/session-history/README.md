# Published lesson identities

`1.3.0.json` preserves the exact challenge IDs of the 79 lessons from the
published `v1.3.0` source tag. That version did not expand `lesson_steps`.
The checked `v1.3.3` lesson plans have identical challenge sets. These are
historical catalog identities, not evidence of a real account migration.

`1.3.6.json` is the exact set of lesson and challenge IDs generated by
the 1.3.6 preview candidate at commit
`c05b3f8ad96a013d77fce07d5dfc5a1ae0c29b01`. It contains IDs only, not
answers or personal data. The signed 1.3.6 preview was published after an
emulator fresh-install and 1.3.0-to-1.3.6 upgrade smoke test.

`1.3.5.json` preserves the IDs produced from the published `v1.3.5` tag using
the same lesson-expansion rules. Four lesson question sets differ between
1.3.5 and the 1.3.6 candidate.

After a version is published, keep its snapshot immutable. A later build can
use its exact sets to validate an old completion proof when questions are
added to a lesson. Do not accept an arbitrary subset of a lesson: doing so
could mark an unfinished session as completed. A new release that changes
lesson membership needs its own snapshot before further changes.

The host tests cover proof validation, not migration of a real account or a
Drive backup. Both still need Android acceptance tests.
